# backup-dir

Compresses selected directory into backup.

---

## Description

Prompts user to select folder for backup and any folders to exclude, then uses tar to form archive (tarball).

* Flexible selection options allow as many additional directories to be excluded as wanted
* Compresses with Gunzip and outputs .tar.gz
* Names backups based on user and timestamp

---

## Quick Start Guide

Run the script with:
```bash
./backup-dir.sh
```
