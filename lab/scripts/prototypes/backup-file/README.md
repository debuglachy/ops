# backup-file

Makes copy of a file in place.

---

## Description

Processes the filename provided as the argument to the script with cp command. 

* Overwrite protection
* Names backups based on user and timestamp

---

## Quick Start Guide

Takes a single file as argument:
```bash
./backup-file.sh file
```
