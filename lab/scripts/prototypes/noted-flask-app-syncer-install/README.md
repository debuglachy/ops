
# noted-flask-app-syncer-install

Script to automate live backups of app data.

---

## Description

* Built on systemd and rsync
* Auto-mounts backup drive
* Checks constantly for new output from [noted-flask-app](https://github.com/debuglachy/noted-flask-app)
* Notes are instantly backed up to secondary drive on creation

---

## Quick Start Guide

Run with:
```bash
./noted-flask-app-syncer-install.sh
```
