
# zeninote

Automates note-taking from user input.

---

## Description

Uses zenity package to prompt user. 

Gathers inputs into a note and timestamps it.

* Tags
* Content
* Optional due date

---

## Quick Start Guide

Create a directory 'noted' inside your home folder and run the script with:
```bash
./zeninote.sh
```

## Prerequisites

Dependencies: zenity
